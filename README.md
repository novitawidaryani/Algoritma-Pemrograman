# 💻 Praktikum Algoritma dan Pemrograman

Selamat datang di repositori GitHub saya! Repositori ini berfungsi sebagai dokumentasi dan portofolio digital untuk tugas praktikum mata kuliah **Algoritma dan Pemrograman**.

Seluruh kode yang ada di dalam repositori ini disusun untuk menyelesaikan *Activity* (latihan atau tugas dasar dengan konsep dan alur logika yang sederhana) dan *Project* (implementasi program yang jauh lebih kompleks dan mendalam) berdasarkan instruksi dari dosen pengampu.
